# Working files

Models, board-set PDFs and other sources for the academic projects, one
folder per project slug. Nothing here is published, and git ignores
everything in this folder except this README: these files are large, change
outside the site, and some are over GitHub's 100 MB limit.

    living-outside-the-box/   board-set PDF, Rhino model (v0.5.0)
    dead-mall-fall/           board-set PDF
    collingsworth-marketplace/ board-set PDF

The same PDFs, and their history, are also in the archived repositories
`hark_portfolio` and `hark_academic`'s predecessors on GitHub. Back this
folder up separately: git does not.
